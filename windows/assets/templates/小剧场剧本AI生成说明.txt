请为“桌搭子”的双 GIF 小剧场生成一个 JSON 剧本，并严格遵守以下要求：

1. 只输出合法 JSON，不要使用 Markdown 代码块，不要添加解释。
2. 根对象包含 name 和 scenes 两个字段。
3. name 是 40 个字符以内的剧本名称。
4. scenes 是 3 至 5 项的数组，建议写满 5 项。
5. 每项只包含 main 和 companion 两个字符串，分别代表主桌宠和登场搭档的台词。
6. 每句台词不超过 60 个字符，不要加入旁白、角色名前缀或动作括号。
7. 五轮剧情建议依次对应：登场、靠近、挑战、换位反转、谢幕。少于五轮时仍要保证开场、发展和结尾完整。
8. 两个角色的性格要有区分，前后内容连贯，整体轻松、有趣、适合桌面弹窗阅读。
9. 不要使用攻击性、色情、仇恨、恐吓或令人不适的内容。

输出结构示例：
{
  "name": "剧本名称",
  "scenes": [
    { "main": "主桌宠第一句", "companion": "搭档第一句" },
    { "main": "主桌宠第二句", "companion": "搭档第二句" },
    { "main": "主桌宠第三句", "companion": "搭档第三句" }
  ]
}
