# 桌搭子 Windows 版

这是桌搭子的 C# / WPF 原生实现。它继续使用旧版的 `%APPDATA%\poko-desktop-pet\settings.json`，因此自定义桌宠、词包、提醒和外观设置会自动迁移。首次运行必须使用管理后台生成的一次性激活码，设备授权加密保存在同目录的 `license.dat`。

## 开发运行

```powershell
dotnet run --project .\windows\ZhuoDazi\ZhuoDazi.csproj -- --settings
```

不带 `--settings` 时只显示桌宠；双击桌宠、双击托盘图标或再次启动程序会打开独立设置窗口。

## 行为系统

- 桌宠会按所选性格在桌面游走、停靠，并追逐或躲避鼠标；鼠标响应和随机走动可独立关闭。
- 拖动后快速松手可以投掷桌宠；移动保留惯性，并在工作区边缘反弹。
- “外观与行为”页可选择活泼、害羞、黏人或混乱性格；随机小剧场可独立开关并设置 1、3、5、10 或 30 分钟间隔，也可随时立即触发。
- 小剧场从当前资源库选择两张不同 GIF，以独立透明窗口完成五轮对白、靠近、跳跃、换位、舞步和退场。
- 可导入最多 10 个 JSON 小剧场剧本；每次演出随机抽取一个，未导入时使用内置性格对白。设置页提供 JSON 模板和 AI 生成说明。
- 内置少量不在界面说明中的低频彩蛋。

## 生成安装包

先安装 .NET 10 SDK 和 Inno Setup 6，然后运行：

```powershell
.\windows\scripts\build-native.ps1 -Version <版本号>
```

输出位于 `windows\dist\ZhuoDazi-Desktop-Pet-<版本号>.exe`。应用内没有更新地址配置项；激活和更新服务地址及 Ed25519 公钥都保留在程序内部。后台发布时上传该安装包即可。

安装后的程序目录按用途整理为：

```text
ZhuoDazi/
├─ ZhuoDazi.exe          # 单文件主程序，已包含 .NET 运行时和应用依赖
├─ resources/            # 内置 GIF 资源库
└─ uninstall/            # 卸载程序
```

“设置 > 外观与行为 > 窗口行为”中的“开机自动启动”开关会写入当前 Windows 用户的启动项。关闭开关或卸载应用时会移除该启动项，不需要管理员权限。

资源库可绑定最多 3 个外部 GIF 目录，并从内置资源库和已绑定目录中选择一个作为当前随机切换来源。互动词包可导入最多 5 个 JSON/TXT 文件，并选择一个用于当前互动；小剧场剧本可导入最多 10 个 JSON 文件并作为随机演出池。旧版的单目录和单词包配置会在首次启动时自动迁移。

## 从 Electron 版迁移

首次迁移需要手动运行一次原生安装包。2.1.0 是激活过渡版本，旧客户端可公开下载；从后续版本开始，检查和下载更新都需要有效设备授权。
