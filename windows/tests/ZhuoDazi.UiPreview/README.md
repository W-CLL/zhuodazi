# Windows 离线界面验收

运行 `dotnet run --project windows/tests/ZhuoDazi.UiPreview -c Release`。验收结束时，在此验收进程的托盘菜单点击“退出桌搭子”；设置窗口右上角的关闭按钮只隐藏窗口，不结束进程。

此入口展示真实的 `SettingsWindow` 与真实托盘菜单，标题包含“离线界面验收”。每次启动使用独立临时目录保存设置、试用凭据与缓存，不读取或覆盖正常安装的数据。所有 `DeskPetHttp` 请求由内存处理器接管，未实现的请求也只返回模拟错误，不会访问生产服务。

提供的模拟状态包括：有效试用、默认未加入大厅、加入后四位在线用户、保存昵称、模拟发送、30 秒发送倒计时，以及一条带长回复的反馈。可检查暂停与恢复、提醒编辑、素材和更新页布局。通过本进程的托盘菜单“退出桌搭子”结束；关闭设置窗口与正式软件一样只隐藏。

这个入口不会启动桌宠、运动计时器、实际提醒或开机注册，因此只用于设置界面与大厅交互验收，不能代替真实双设备投递、桌宠动画和系统权限测试。

`GifLibraryService.Checks` 运行逻辑回归。设置 `ZHUODAZI_SETTINGS_PREVIEW_DIR` 后，还会从真实 XAML 生成 900 / 1000 像素宽的离线大厅与勿扰布局预览，并检查大厅不需要横向滚动。
