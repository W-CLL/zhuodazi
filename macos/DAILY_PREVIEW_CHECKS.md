# 3.4.0 日常功能本地验收

本轮在 Windows 编辑源码。没有可用的 Swift、Xcode、macOS 桌面或远程 Mac，因此 **尚未运行 Swift 编译、XCTest、AppKit 界面测试和应用打包**。静态语法解析仅能发现语法问题，不能替代这些验证。

已完成的本机检查：全部 38 个 Swift 文件经 tree-sitter 解析；新增文件无语法错误，三个旧文件的解析器局限与 git 基线一致。`git diff --check -- macos` 通过。新增 `DailyJournalTests.swift` 中 15 项测试，待在 Mac 执行。

在 macOS 13+、Xcode Command Line Tools / Swift 5.10+ 执行：

```bash
cd macos
swift test
swift build --configuration release
bash scripts/test-display-lifecycle.sh
bash scripts/build-app.sh
```

打包脚本产出 `dist/ZhuoDazi-macOS-3.4.0-<架构>.app` 与同名 ZIP，仅本地构建，不发布。当前尚无本轮验证过的 macOS 二进制。

核心测试覆盖新旧频率、八种心情、原子持久化/重复 ID/账号隔离、损坏文件保护、答题与心情计数、周五结算边界、七天半开区间（含周末）、次月 1 日指定时间、闰月/跨年、不可提前查看、模板轮换/禁用/未知占位符/缺失配置、保留原记录本地时间、明确延后一次、跨午夜与 DST。

桌面验收：

1. 旧安装升级后原 60–120 / 30–60 / 10–30 分钟保留。新安装默认 10–30 分钟；设置可选择 5–15 / 10–30 / 15–40 分钟。线上旧 profile 刷新不会覆盖新频率，也不会反复重置倒计时。
2. 设置进入“我们的日常”，分别点击记下心情、一起答题、聊聊下班。心情有八种选项，关闭/跳过不计数；多次点击和旧卡回调不重复记账。答题只取数学/知识/谜语，揭晓答案不计作答，明确选答后才计数。
3. 统计提供本周、本月、全部，显示累计答题和答对数；月历只显示每天最后一次心情。没有逐条“日常记录”列表及修改/删除入口。
4. 开启作息，选择工作日和 HH:mm 下班时间。在桌宠可见、未暂停、非穿透、未忙碌、设备近期有输入时到点出现提醒；下班/休息结束当天提醒，加班只有主动选 30/60 分钟才延后一次，今天六点只影响当天。关闭弹窗不自动延后，错过超过 30 分钟不补发。重启仍记得当日提醒状态。主动心情每天最多两次、相隔至少三小时；连续两次未答或选择低落心情后至少 30 分钟减少主动打扰。
5. 后台系统设置改变 `dailySummaries` 周总结星期/时间、月总结时间、标题/正文/开关。点击“同步总结设置”、重新启动或最多 15 分钟后同步。周总结仅展示已结算前七天，月总结仅展示完整过去月份；最新/前一份/后一份导航不能进入未结算周期。没有记录、没有配置、服务端关闭均显示对应状态，不编造正文。
6. 已有本机记录重启仍在，退出/更换绑定账号不混入另一账号数据。手动下载离线包、题库数量、手动补题按钮均不存在，正常在线自动获取题目仍可用。

日常明细保留在本机账号独立文件。八种心情仅在本机保存，不映射成旧 happy/okay/low 上传；没有新增远程日常明细上传。后台模板配置仍需通过相应后端提供，本轮没有部署后端。
