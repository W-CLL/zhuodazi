# macOS 3.3.0 更新说明

## 一分钟，认识桌搭子

- 新增持久四步使用引导：认识操作、体验互动、看段短剧、学会暂停和找回。可以随时跳过、关闭、继续或重播。
- 本地示例不依赖网络、好友和导入，试看不会开启自动剧场；教学暂时抑制自动行为，真实来访保留。
- 已有用户升级只看到一次可关闭的新功能提示，不重置设置或强制重学。
- 小剧场先展示玩法和手动观看，设置页激活后接续原操作；隐藏或忙碌时给出明确反馈。

完整更新文案见 [3.3.0 桌面说明](../docs/releases/desktop-3.3.0.md)。

## 桌宠大厅，单独逛一逛

- 菜单新增独立“桌宠大厅”窗口。七天有效体验期间也可以加入大厅，给在线用户发送当前 GIF 和一句留言。
- 加入前会说明哪些信息将公开；新用户主动选择加入后才出现在大厅。可随时退出，私人搭子关系不受影响。
- 大厅展示昵称、其他在线用户数量、用户列表、当前 GIF 预览、收件人、发送结果和冷却倒计时。空列表、连接中和错误状态也有明确提示。
- 昵称最多 12 字，留言最多 120 字。每 30 秒可发送一次；对方最多保留 3 条待接收来访，24 小时未接收会过期。“设备接收”表示来访已保存到对方设备，不代表对方已经阅读。
- “私人搭子”仍需正式激活，拥有独立入口。窗口说明搭子码在同一账号设备间共享，以及解除绑定的影响。

## 忙的时候，让陪伴安静一点

- 新增“日常台词”开关，默认开启；可独立关闭鼠标追随、边缘碰撞、自动换宠触发的日常台词。
- 菜单与设置均可“暂停打扰 1 小时”，也能提前恢复。暂停会停止主动台词、自动互动、自动小剧场和来访展示；手动互动及到点提醒仍可使用。暂停截止时间会保存，重启后继续生效。
- 新增“停止当前剧场或来访”，可结束正在演出的场景。
- 使用说明可从菜单与设置重新打开，说明拖动、右键、隐藏、完全退出及大厅入口。

## 提醒和来访更可靠

- 到点提醒先保存在本机等待展示，桌宠忙碌或隐藏时排队；恢复后继续提醒。应用重启不会清掉已保存的待展示提醒。
- 每日提醒按原定本地时刻安排下一次，避免跨午夜补发后跳过当天提醒。
- 收到的 GIF 会先校验并保存，再发送设备接收回执；显示完成后才清理。隐藏或暂停中断的来访会保留，以便稍后重新展示。
- 同一设备从体验期首次激活时，已保存但未看的体验来访会继续保留；切换到另一个正式账号时，不会混入前一个账号的来访。
- 移除原先没有实际效果的提醒“情绪”选择，保留可见的提醒文字和 GIF 表情设置。

## 说明与基础体验

- “我的桌宠”显示当前实际 GIF 与来源，增加清楚的“返回内置图鉴”按钮。手动换一只不会改变自动换宠开关。
- 反馈详情支持滚动和复制，可完整查看原文、处理状态及后台回复。更新页也能查看本次更新说明。
- 设置页支持滚动，补充自动保存、账号同步、互动内容和提醒运行条件的说明。
- 未激活和体验结束的用户也能检查、下载公开更新。
- 首次启动等待远程默认设置加载后再同步互动配置，避免默认值误覆盖账号原有偏好。

提醒需要桌搭子保持运行。macOS 系统通知是否显示仍由系统通知权限和专注模式决定。
