# 桌搭子 macOS 版

这是使用 Swift 与 AppKit 实现的原生 macOS 3.3.0 版，最低支持 macOS 13。

## 当前功能

- 透明、无边框、跨桌面的 GIF 桌宠窗口
- 拖拽投掷、惯性和屏幕可见区域边缘反弹
- 跟随鼠标和随机移动，可从菜单栏独立开关
- 随机心情问候、冷笑话、数学题、趣味知识、脑筋急转弯、生活小贴士和关怀互动，可选择安静、标准或活跃频率
- 互动配置随设备账号同步；内容使用 Ed25519 签名与 SHA-256 校验，支持账号隔离缓存和离线内容包
- 互动展示、笑话揭晓、答题结果和心情回应会在本机排队，并分批上传行为事件
- 自动随机换宠和立即换一只；使用系统随机源，轮内不会重复 GIF
- 双桌宠小剧场包含入场、同步跳跃、交换位置、错位摇摆和归位动作
- 菜单栏显示/隐藏和退出
- 独立桌宠大厅：有效体验与正式激活用户均可主动加入，修改 12 字昵称，查看在线列表，预览并发送当前 GIF 与最多 120 字留言；提供加载、空状态、错误重试与 30 秒发送冷却提示
- 私人搭子单独入口，正式激活后绑定另一账号；同一账号设备共用搭子码
- 日常台词独立开关、暂停打扰 1 小时、立即恢复、停止当前剧场或来访，以及可重复打开的使用说明
- 摸鱼广告壳：将抖音窗口拖入右下角广告壳后自动贴合，保留正常点击和滚动；首次使用需授权辅助功能
- Dock 应用图标与 App 图标；可在设置中切换是否显示 Dock 图标
- 设置窗口：跟随鼠标、随机移动、自动换宠和始终置顶都会保存到本机
- 首次使用可完整体验 7 天；体验期内可使用摸鱼广告、互动、小剧场、提醒、内容导入和大厅，并可点菜单模仿女友、好友、搭子来访。之后保留 3 个自定义桌宠、1 个内置资源库和基础陪伴；正式激活后继续使用高级功能并可绑定私人搭子
- 提醒可指定 GIF 表情，显示 6 秒后恢复当前桌宠；到点记录先持久化，忙碌、隐藏或应用重启后继续排队，每日提醒保持原定本地时刻。提醒需要应用保持运行；系统通知受 macOS 权限和专注模式影响
- 接收到的来访先校验并保存，再发送设备接收回执；展示完成后清理。隐藏或暂停导致的中断会保留待展示记录
- “反馈与建议”页支持提交问题或功能建议，滚动查看和复制完整原文、处理状态及后台回复；每台设备最多同时保留 3 条待处理或进行中的反馈
- 在线更新向未激活用户开放，可在设置查看更新说明；仅获取当前 CPU 架构的 macOS ZIP，校验 Ed25519 清单签名和 SHA-256 后自动替换 App 并重启

随机换宠会扫描 App 包内 `Resources/Pets/yuexinmiao` 目录中的全部 GIF。打包脚本会复用 Windows 版的 54 张内置“月薪喵”资源。默认每 30 秒自动切换一次；每轮会以随机顺序使用完所有 GIF，再重新生成下一轮顺序，并避免两轮交界处连续显示同一张。

## 默认行为与打扰控制

本地初始设置：尺寸 140、透明度 100%、始终置顶开启、跟随鼠标开启、随机移动开启、随机互动开启、日常台词开启、自动换宠开启且间隔 30 秒；自动小剧场关闭、开机启动关闭、点击穿透关闭、水平镜像关闭；Dock 图标与自动检查更新开启。默认没有自定义资源、提醒或暂停截止时间。每次重启会退出点击穿透，避免无法操作。

首次联网成功后，尚未自行修改相关设置的新设备会采用服务端的人设、互动频率和小剧场间隔默认值；账号已有互动偏好优先同步。离线备用值为活泼人设、标准互动频率、小剧场间隔 5 分钟。旧设备已保存的设置不会被重新当作首次默认值覆盖。

大厅加入状态随账号保存。新账号默认不加入，必须主动确认；已有账号的加入选择保留。暂停打扰会抑制主动内容与来访展示，保留手动操作和到点提醒；“日常台词”开关仅影响被动触发的日常台词，不关闭互动题或小剧场。

本次面向用户的变更详见 [更新说明](RELEASE_NOTES.md)。

## 本机开发

需要安装 Xcode Command Line Tools：

```bash
cd macos
swift run ZhuoDaziMac
```

运行核心逻辑测试：

```bash
swift test
```

生成测试包：

```bash
bash macos/scripts/build-app.sh
```

输出位于 `macos/dist/`。脚本使用 ad-hoc 签名，不需要 Apple Developer 账号，但首次打开需要在 macOS“隐私与安全性”设置中手动允许。

## GitHub Actions

`Build macOS` 工作流分别使用 Apple Silicon 与 Intel runner 编译，并上传：

从 `2.0.0` 开始，App、ZIP 和 GitHub Actions Artifact 都包含三段式版本号。当前版本示例：

- `ZhuoDazi-macOS-3.3.0-arm64.zip`
- `ZhuoDazi-macOS-3.3.0-x86_64.zip`

macOS 与 Windows 独立管理版本号。macOS 新包上传到 `macos-v3.3.0` Draft Release；Windows 没有应用改动时保留原版本并跳过构建。旧版统一 Release 仍然保留，已发布的安装包不会被覆盖。

在线更新后台按 `macos/arm64` 与 `macos/x86_64` 分别上传、发布，不能上传 Windows EXE。以后配置 Developer ID 和公证凭据时，可在现有打包脚本后追加正式签名、公证和 DMG 步骤。
