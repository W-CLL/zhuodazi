# 桌搭子 macOS 版

这是使用 Swift 与 AppKit 实现的原生 macOS 3.2.0 版，最低支持 macOS 13。

## 当前功能

- 透明、无边框、跨桌面的 GIF 桌宠窗口
- 拖拽投掷、惯性和屏幕可见区域边缘反弹
- 跟随鼠标和随机移动，可从菜单栏独立开关
- 随机心情问候、冷笑话、数学题、趣味知识、脑筋急转弯、生活小贴士和关怀互动，可选择安静、标准或活跃频率
- 互动配置随设备账号同步；内容使用 Ed25519 签名与 SHA-256 校验，支持账号隔离缓存和离线内容包
- 互动展示、笑话揭晓、答题结果和心情回应会在本机排队，并分批上传行为事件
- 自动随机换宠和立即换一只；使用系统随机源，轮内不会重复 GIF
- 双桌宠小剧场包含入场、同步跳跃、交换位置、错位摇摆和归位动作
- 菜单栏显示/隐藏和退出
- Dock 应用图标与 App 图标；可在设置中切换是否显示 Dock 图标
- 设置窗口：跟随鼠标、随机移动、自动换宠和始终置顶都会保存到本机
- 首次使用可完整体验 1 天；体验期内可点菜单模仿女友、好友、搭子来访，表情从线上库随机抽一张。之后保留 3 个自定义桌宠、1 个内置资源库和基础陪伴，激活后解锁互动、小剧场、提醒、内容导入和发给搭子
- 提醒可指定 GIF 表情，到点后临时切换并在 6 秒后恢复当前桌宠
- “反馈与建议”页支持提交问题或功能建议、查看处理状态和后台回复；每台设备最多同时保留 3 条待处理或进行中的反馈
- 在线更新：仅获取当前 CPU 架构的 macOS ZIP，校验 Ed25519 清单签名和 SHA-256 后自动替换 App 并重启

随机换宠会扫描 App 包内 `Resources/Pets/yuexinmiao` 目录中的全部 GIF。打包脚本会复用 Windows 版的 54 张内置“月薪喵”资源。默认每 30 秒自动切换一次；每轮会以随机顺序使用完所有 GIF，再重新生成下一轮顺序，并避免两轮交界处连续显示同一张。

## 本机开发

需要安装 Xcode Command Line Tools：

```bash
cd macos
swift run ZhuoDaziMac
```

运行核心逻辑测试：

```bash
swift test
```

生成测试包：

```bash
bash macos/scripts/build-app.sh
```

输出位于 `macos/dist/`。脚本使用 ad-hoc 签名，不需要 Apple Developer 账号，但首次打开需要在 macOS“隐私与安全性”设置中手动允许。

## GitHub Actions

`Build macOS` 工作流分别使用 Apple Silicon 与 Intel runner 编译，并上传：

从 `2.0.0` 开始，App、ZIP 和 GitHub Actions Artifact 都包含三段式版本号。当前版本示例：

- `ZhuoDazi-macOS-3.2.0-arm64.zip`
- `ZhuoDazi-macOS-3.2.0-x86_64.zip`

在线更新后台按 `macos/arm64` 与 `macos/x86_64` 分别上传、发布，不能上传 Windows EXE。以后配置 Developer ID 和公证凭据时，可在现有打包脚本后追加正式签名、公证和 DMG 步骤。
