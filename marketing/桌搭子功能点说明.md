# 桌搭子功能点说明

> 整理日期：2026-09-20；对应本地待验收版本，尚未发布。<br>
> 电脑版：Windows / macOS **v3.3.0**<br>
> 手机版：Android **v1.4.0**<br>
> 官网：https://desktoppet.online  
> 下载：https://desktoppet.online/download/

桌搭子是住在屏幕边角的 GIF 桌宠。可以自己养一只，也可以派一张表情去对方电脑或手机上坐一会儿。不是聊天软件，也不催回复。

---

## 一句话能力

1. **桌角养一只 GIF**：透明、可拖、会走，不挡正事。
2. **发给搭子**：点一下，当前这张 GIF 去对面桌面或手机角落坐一会儿。
3. **在线串门**：有效体验期也可以在独立大厅里，把桌宠送给在线朋友。
4. **电脑摸鱼**：有效体验或正式激活后可把抖音桌面端装进右下角「广告弹窗」壳里。

## 1. 桌宠本体

### 显示

- 透明 GIF，无边框，常驻屏幕边角。
- 不进任务栏打扰（电脑）；安卓是系统悬浮窗，需允许「显示在其他应用上层」。
- 可调大小、透明度、水平镜像、始终置顶。

### 动作

- 按性格在桌面游走、停靠。
- 性格四档：**活泼 / 害羞 / 黏人 / 混乱**。
- 可独立开关：跟随或躲避鼠标、随机走动。
- 拖动后快速松手可投掷；带惯性，碰到工作区边缘会弹回来。
- 安卓：窗口会按屏幕收紧，旋转后重新贴边。

### 入口

- Windows：双击桌宠、双击托盘、再次启动程序 → 打开设置。托盘可隐藏 / 显示桌宠。
- macOS：菜单栏显示 / 隐藏、退出；设置里可开关 Dock 图标。
- Android：点桌宠出快捷菜单；隐藏或开启穿透后，用常驻通知唤回。
- 大厅有独立入口：Windows 设置页与托盘，macOS 独立窗口与菜单栏，Android 底部“大厅”。Android 私人搭子从“我的搭子”独立页进入。
- 关闭设置不会退出桌宠；完全退出请使用托盘、菜单栏或常驻通知中的退出操作。
- 新手说明可以重新查看，不必依赖首次出现的几秒气泡。

## 2. 形象与图鉴

### 内置图鉴

- 电脑内置「月薪喵」约 54 张 GIF，可随机轮换。
- 安卓内置 10 只，可随机或手动换。

### 自定义 GIF

- 各端最多保留 **3 个**自定义透明 GIF。
- 随时切换当前角色。
- 桌面基础版也可以新增和使用这 3 个；Android 新增 GIF 要正式激活。基础拖动、走动和内置图鉴长期可用。

### 外部图鉴目录（高级）

- 最多绑定 **3 个**外部 GIF 文件夹。
- 每个目录递归扫描，最多 **500** 张。
- 可从内置图鉴或其中一个目录选当前轮换来源。
- 随机换宠间隔：30 秒 / 1 / 5 / 10 / 30 分钟，也可立即换一只。
- 手动换一只不再顺便打开自动轮换。桌面默认每 30 秒，Android 默认每 5 分钟换宠。
- 安卓用系统「打开文件夹」授权；卸载后权限失效，需重新选。

## 3. 大厅与私人搭子

### 公开大厅

- 有效七天体验与正式激活均可使用；初次默认不加入，用户主动选择公开在线。
- 独立大厅入口显示在线人数与用户卡片，可以选中收件人、预览当前 GIF、填写留言后发送。
- 昵称最多 12 个字符，留言最多 120 字；发送 GIF 不超过 8MB，宽高不超过 2048。
- 普通发送间隔至少 30 秒；接收账号最多 3 条待收投递，有效期 24 小时。
- 随时退出大厅不影响已经绑定的私人搭子，另一台新设备不会重新打开账号已关闭的大厅选择。
- “设备已接收”表示文件送到设备，不代表用户已经看见。隐藏、穿透或勿扰时，来访进入本机待看队列，恢复后展示。
- 体验后激活会衔接昵称、大厅选择和来访；加入已有账号时，已有账号的选择优先。

### 私人搭子

这是桌搭子和其他桌宠最大的差别。

### 怎么连

- 两位都已**正式激活**的用户，在设置「搭子」里交换 **8 位搭子码**，只绑一个人。
- 一组 **6 位购买码**最多填 **两台设备**（例如电脑 + 手机），进入同一个账号，搭子关系不用重绑。
- 情侣要各买一次。两人共用一组购买码，会变成自己和自己配对。

### 发出去会怎样

- 发送的是**此刻选中的那张 GIF**。
- 对方看到的是独立来访窗口，坐一会儿自己走。
- **不顶掉、不替换**对方原来的桌宠。
- 对方暂时不在，投递最多等 **24 小时**。
- 电脑和手机分别记录设备回执，同一账号两台设备可以各收一次；回执不等于已读。

### 体验期来访（不是真搭子）

- 体验期内可点「模仿女友 / 好友 / 搭子来访」。
- 表情从线上库随机抽一张，用来演示「有人来串门」。
- 向真实搭子发 GIF，必须正式激活。

## 4. 随机互动

- 三档频率：**安静 / 标准 / 热闹（活跃）**。
- 内容类型：心情问候、冷笑话、数学题、趣味知识、脑筋急转弯、生活小贴士、关怀。
- 没有签到。托盘 / 设置 / 安卓菜单都可立即来一条。
- 在线内容带签名校验；可下离线包，没网也能用。
- 桌面有显式离线包入口，Android 以自动缓存补货为主；已有缓存可以离线用，新内容仍需联网。
- 主动互动开关、频率按账号同步；已有账号选择不会被新安装默认覆盖，行为事件分批上传。
- 日常台词可单独关闭；暂停打扰一小时会暂缓主动气泡、自动互动、剧场和来访展示，提醒与手动操作仍可用。
- 这三档频率不代表所有日常气泡统一使用同一计时器。当前没有内置自由 AI 聊天、语音识曲或可消费积分商城。

### 互动词包（高级）

- Windows/macOS 可导入 JSON 或 TXT，最多 **5 套**，同时只用一套；Android 选择内置词包。
- 设置页提供模板和 AI 生成说明。
- 当前工作树词包示例：抽象大师、纯爱战士（已黑化）、互联网嘴替、精神状态.jpg。打包时以当前资源目录为准。

## 5. 小剧场

- 从当前图鉴挑 **两张不同 GIF**，在透明窗口里演一小段。
- 流程：对白、靠近、跳跃、换位、舞步、退场。
- 可独立开关；随机间隔 1 / 3 / 5 / 10 / 30 分钟，也可立即上演。
- 可导入最多 **10 个** JSON 剧本；每个剧本 3～5 轮双人对白。
- 没导入时用内置性格对白。
- 安卓内置三场对白，同样支持导入剧本。

## 6. 提醒

- 最多 **20** 条。
- 可设日期、时间、文案、是否每天重复。
- 可给每条指定一张 GIF：到点后桌宠临时换成这张表情，说完再换回来。
- 电脑会气泡提示；安卓另弹通知（约 20 秒轮询，不申请精确闹钟）。
- macOS 约 15 秒检查一次，也会请求系统通知；Windows 约 1 秒检查一次。系统通知取决于权限。
- 需要保持应用或悬浮服务运行，退出、休眠和系统省电可能影响提醒，不应当作系统级精确闹钟。
- 首次安装提醒列表为空；新建表单默认十分钟后、“休息一下吧”、启用、非每天重复、无专用 GIF。

## 7. 摸鱼模式（电脑体验 / 正式激活）

Windows / macOS 有效体验或正式激活后可用，安卓没有。

操作：

1. 打开抖音桌面端，把当前视频放大。
2. 从设置或托盘 / 菜单栏打开「摸鱼广告」。
3. 把放大后的抖音窗口拖进右下角广告壳。

嵌入后仍可上下滑、点击、自动播放。广告壳可移动、临时隐藏；Windows 提供标准 560×360 与紧凑 440×280 两档。关掉壳，里面的视频一起关。

macOS 第一次用，要在系统设置里打开「辅助功能」权限，再重新打开摸鱼广告。

外观像网页广告浮窗（「广告」角标、红包 / 会员 / 秒杀文案），实际是自己的摸鱼窗口。不自动乱弹。

## 8. 试用、激活、付费边界

### 试用

- 每台安装 **第一次**可体验高级功能 **7 天**（按 installationId，用过的不会自动再开）。
- 体验期可用：高级互动、平台支持的词包能力、小剧场、提醒、外部图鉴、模仿来访、公开大厅、电脑摸鱼。
- 体验期不开放：一对一真实搭子绑定/私密发送、Android 新增自己的 GIF。大厅发送不需要先绑定搭子。

### 体验结束后仍免费

- 基础桌宠、拖动、走动、内置图鉴。
- 桌面最多 3 个自定义 GIF 新增与使用；Android 新增仍需正式激活。

### 正式激活后解锁

- 发给搭子。
- Android 新增自定义 GIF；体验期的大多数高级功能可以继续使用，包括电脑摸鱼与大厅。
- 互动、小剧场、提醒、词包 / 剧本导入、外部图鉴（体验期已试用过的，激活后继续用）。

### 码不要混

| 码 | 位数 | 用途 |
|---|---|---|
| 购买码 | 6 位 | 激活设备。一组最多 2 台，进同一账号 |
| 搭子码 | 8 位 | 和一位熟人绑定发 GIF |
| 换机码 | — | 新设备成功绑定后撤销该账号全部旧设备授权，账号和搭子关系保留 |

价格、定制、发货以当前购买入口的说明为准。

## 9. 系统与安装

| 平台 | 要求 | 安装包 |
|---|---|---|
| Windows | Win10 22H2 / Win11，x64 | 正式发布使用 EXE 安装包；本地验收包说明另附 |
| macOS | 13+，Apple 芯片与 Intel 分开 | ZIP，拖进「应用程序」 |
| Android | Android 9+，ARM64 / ARMv7 | 对应架构 APK |

常见拦截：

- Windows SmartScreen：更多信息 → 仍要运行。
- macOS：系统设置 → 隐私与安全性 允许打开。摸鱼还需辅助功能。
- Android：允许悬浮窗；安装未知应用。

本地外观、GIF、图鉴路径、词包、剧本、提醒不作为完整云备份；账号、激活、搭子资料以及主动互动频率/开关有相应同步。

## 10. 其它

- **反馈**：电脑可提交问题 / 建议，查看处理状态和回复；每台设备最多 3 条进行中。
- **更新**：基础版也能检查公开更新，签名清单校验后下载；Windows / macOS / Android 渠道分开。
- **低频彩蛋**：电脑有少量不在界面里写的彩蛋（例如零点）。
- **安卓首页**：提供首次体验、说句话、小剧场和演示来访入口；真实大厅与私人搭子分开说明。

## 对外怎么讲（短版）

> 桌搭子住在电脑或手机屏幕边角，陪你走动、演小剧场，也能把一张表情送到朋友屏幕上。七天体验可以先逛逛大厅，向在线朋友送出桌宠；想和熟人长期互相串门，正式激活后再绑定一对一搭子。

对外三条不要讲错：

1. 安卓是悬浮窗，不是壁纸。
2. 来访不替换原来的桌宠。
3. 一组购买码是两台设备，不是两个人。
