# 桌搭子功能点说明

> 整理日期：2026-08-21  
> 电脑版：Windows / macOS **v3.2.1**  
> 手机版：Android **v1.3.5**  
> 官网：https://desktoppet.online  
> 下载：https://desktoppet.online/download/

桌搭子是住在屏幕边角的 GIF 桌宠。可以自己养一只，也可以派一张表情去对方电脑或手机上坐一会儿。不是聊天软件，也不催回复。

---

## 一句话能力

1. **桌角养一只 GIF**：透明、可拖、会走，不挡正事。
2. **发给搭子**：点一下，当前这张 GIF 去对面桌面或手机角落坐一会儿。
3. **电脑摸鱼**：完整版可把抖音桌面端装进右下角「广告弹窗」壳里。

## 1. 桌宠本体

### 显示

- 透明 GIF，无边框，常驻屏幕边角。
- 不进任务栏打扰（电脑）；安卓是系统悬浮窗，需允许「显示在其他应用上层」。
- 可调大小、透明度、水平镜像、始终置顶。

### 动作

- 按性格在桌面游走、停靠。
- 性格四档：**活泼 / 害羞 / 黏人 / 混乱**。
- 可独立开关：跟随或躲避鼠标、随机走动。
- 拖动后快速松手可投掷；带惯性，碰到工作区边缘会弹回来。
- 安卓：窗口会按屏幕收紧，旋转后重新贴边。

### 入口

- Windows：双击桌宠、双击托盘、再次启动程序 → 打开设置。托盘可隐藏 / 显示桌宠。
- macOS：菜单栏显示 / 隐藏、退出；设置里可开关 Dock 图标。
- Android：点桌宠出快捷菜单；隐藏或开启穿透后，用常驻通知唤回。

## 2. 形象与图鉴

### 内置图鉴

- 电脑内置「月薪喵」约 54 张 GIF，可随机轮换。
- 安卓内置 10 只，可随机或手动换。

### 自定义 GIF

- 各端最多保留 **3 个**自定义透明 GIF。
- 随时切换当前角色。
- 体验结束后仍可继续用这 3 个，以及基础拖动、走动、内置图鉴。

### 外部图鉴目录（高级）

- 最多绑定 **3 个**外部 GIF 文件夹。
- 每个目录递归扫描，最多 **500** 张。
- 可从内置图鉴或其中一个目录选当前轮换来源。
- 随机换宠间隔：30 秒 / 1 / 5 / 10 / 30 分钟，也可立即换一只。
- 安卓用系统「打开文件夹」授权；卸载后权限失效，需重新选。

## 3. 发给搭子

这是桌搭子和其他桌宠最大的差别。

### 怎么连

- 两位都已**正式激活**的用户，在设置「搭子」里交换 **8 位搭子码**，只绑一个人。
- 一组 **6 位购买码**最多填 **两台设备**（例如电脑 + 手机），进入同一个账号，搭子关系不用重绑。
- 情侣要各买一次。两人共用一组购买码，会变成自己和自己配对。

### 发出去会怎样

- 发送的是**此刻选中的那张 GIF**。
- 对方看到的是独立来访窗口，坐一会儿自己走。
- **不顶掉、不替换**对方原来的桌宠。
- 对方暂时不在，投递最多等 **24 小时**。
- 电脑看过之后，手机仍能领同一封；任意一端先看过，就算送达。

### 体验期来访（不是真搭子）

- 体验期内可点「模仿女友 / 好友 / 搭子来访」。
- 表情从线上库随机抽一张，用来演示「有人来串门」。
- 向真实搭子发 GIF，必须正式激活。

## 4. 随机互动

- 三档频率：**安静 / 标准 / 热闹（活跃）**。
- 内容类型：心情问候、冷笑话、数学题、趣味知识、脑筋急转弯、生活小贴士、关怀。
- 没有签到。托盘 / 设置 / 安卓菜单都可立即来一条。
- 在线内容带签名校验；可下离线包，没网也能用。
- 互动设置按激活账号隔离，行为会分批同步。

### 互动词包（高级）

- 可导入 JSON 或 TXT，最多 **5 套**，同时只用一套。
- 设置页提供模板和 AI 生成说明。
- 仓库现成词包示例：温柔陪伴、冷面吐槽、打工摸鱼、元气夸夸。

---

## 5. 小剧场

- 从当前图鉴挑 **两张不同 GIF**，在透明窗口里演一小段。
- 流程：对白、靠近、跳跃、换位、舞步、退场。
- 可独立开关；随机间隔 1 / 3 / 5 / 10 / 30 分钟，也可立即上演。
- 可导入最多 **10 个** JSON 剧本；每个剧本 3～5 轮双人对白。
- 没导入时用内置性格对白。
- 安卓内置三场对白，同样支持导入剧本。

---

## 6. 提醒

- 最多 **20** 条。
- 可设日期、时间、文案、是否每天重复。
- 可给每条指定一张 GIF：到点后桌宠临时换成这张表情，说完再换回来。
- 电脑会气泡提示；安卓另弹通知（约 20 秒轮询，不申请精确闹钟）。

## 7. 摸鱼模式（仅电脑完整版）

Windows / macOS 正式激活后可用，安卓没有。

操作：

1. 打开抖音桌面端，把当前视频放大。
2. 从设置或托盘 / 菜单栏打开「摸鱼广告」。
3. 把放大后的抖音窗口拖进右下角广告壳。

嵌入后仍可上下滑、点击、自动播放。广告壳可移动、缩放、临时隐藏。关掉壳，里面的视频一起关。

macOS 第一次用，要在系统设置里打开「辅助功能」权限，再重新打开摸鱼广告。

外观像网页广告浮窗（「广告」角标、红包 / 会员 / 秒杀文案），实际是自己的摸鱼窗口。不自动乱弹。

## 8. 试用、激活、付费边界

### 试用

- 每台安装 **第一次**可完整体验 **7 天**（按 installationId，用过的不会自动再开）。
- 体验期可用：高级互动、词包、小剧场、提醒、外部图鉴、模仿来访。
- 体验期**不能**：发给真实搭子、电脑摸鱼模式。

### 体验结束后仍免费

- 基础桌宠、拖动、走动、内置图鉴。
- 最多 3 个自定义 GIF。

### 正式激活后解锁

- 发给搭子。
- 电脑摸鱼。
- 互动、小剧场、提醒、词包 / 剧本导入、外部图鉴（体验期已试用过的，激活后继续用）。

### 码不要混

| 码 | 位数 | 用途 |
|---|---|---|
| 购买码 | 6 位 | 激活设备。一组最多 2 台，进同一账号 |
| 搭子码 | 8 位 | 和一位熟人绑定发 GIF |
| 换机码 | — | 撤销该账号全部有效授权后再换设备 |

价格、定制、发货以闲鱼沟通为准。不要改试用时长和付费墙，除非产品侧明确要求。

## 9. 系统与安装

| 平台 | 要求 | 安装包 |
|---|---|---|
| Windows | Win10 22H2 / Win11，x64 | EXE，约 54 MB，自带运行环境 |
| macOS | 13+，Apple 芯片与 Intel 分开 | ZIP，拖进「应用程序」 |
| Android | ARM64 | APK，约 46 MB |

常见拦截：

- Windows SmartScreen：更多信息 → 仍要运行。
- macOS：系统设置 → 隐私与安全性 允许打开。摸鱼还需辅助功能。
- Android：允许悬浮窗；安装未知应用。

本地桌宠、GIF、词包、提醒**不跨设备同步**，只同步账号、激活和搭子关系。

## 10. 其它

- **反馈**：电脑可提交问题 / 建议，查看处理状态和回复；每台设备最多 3 条进行中。
- **更新**：应用内检查签名清单后下载；Windows / macOS / Android 渠道分开。
- **低频彩蛋**：电脑有少量不在界面里写的彩蛋（例如零点）。
- **安卓首页**：体验期主按钮是「女友来访」，不把「发给搭子」放第一位。

对外三条不要讲错：

1. 安卓是悬浮窗，不是壁纸。
2. 来访不替换原来的桌宠。
3. 一组购买码是两台设备，不是两个人。
