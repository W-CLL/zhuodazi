# 桌搭子 DeskPet：电脑和安卓都能用的 GIF 桌宠，搭子联机 + 电脑版摸鱼模式

桌搭子是一款住在屏幕边角的 GIF 桌宠软件，支持 Windows、macOS 和 Android。电脑端当前版本为 v3.2.1，安卓版当前版本为 v1.3.5；这是数字软件，不寄送实体商品。

它不只是把一张动图放在桌面上。你可以养自己的 GIF，让桌宠走动、互动、演小剧场；正式激活后，还能和一位熟人绑定，把当前 GIF 发到对方的电脑或手机上。Windows 和 macOS 完整版另有摸鱼模式。

## 安卓版：刷短视频、回微信，桌宠都能待在角落

安卓版不是动态壁纸，而是系统悬浮窗。安装后允许“显示在其他应用上层”，桌宠就能悬浮在短视频、微信等应用的画面上。

它可以拖动、投掷、随机走动，也能手动换宠。隐藏桌宠或开启触摸穿透后，可从常驻通知恢复，不必反复打开 App。

正式激活并绑定搭子后，手机也能把当前 GIF 发给对方。对方收到的是一个独立访客，不会替换原来养着的桌宠；临时离线时，投递可等待领取。

电脑和手机用的是同一套账号体系。一组 6 位购买码最多激活两台设备，例如一台电脑加一部手机；同一位用户换到手机端时，不需要重新注册搭子关系。本地桌宠、GIF、词包和提醒仍分别保存在各自设备上，不会自动跨设备同步。

**手机端不是电脑版的附赠说明页，而是一套可以实际使用的悬浮桌宠。**

## 电脑版：把一张 GIF 发去对方桌面坐一会儿

Windows 和 macOS 都支持搭子联机。两个人分别完成激活，在“搭子”页面交换 8 位搭子码并绑定后，就能把当前 GIF 发给对方。

发送的是此刻选中的 GIF。它会作为独立访客出现在对方桌角，停留一会儿再离开，不顶掉对方原本的桌宠。适合拿来发一句“起床了吗”“抱一下”或“该下班了”，不用再弹一个催回复的聊天窗口。

这里有两组不同的码：6 位购买码用于激活设备，8 位搭子码用于绑定一位熟人，不要混用。每位使用者都需要自己的购买与激活；一组购买码最多两台设备，不等于两个人共用一次购买。

## v3.2.1 摸鱼模式：把抖音桌面端装进右下角广告壳

电脑版 v3.2.1 增加了摸鱼模式，Windows 和 macOS 完整版都可使用。

真实操作只有三步：

1. 打开抖音桌面端，在首页把当前视频放大。
2. 从桌搭子设置或托盘 / 菜单栏打开“摸鱼广告”。
3. 把放大后的抖音窗口拖进右下角广告壳。

嵌入以后，视频仍能上下滑动、点击和自动播放。广告壳可以移动、缩放，也可以临时隐藏；关闭广告壳时，嵌入的视频会同步关闭。

macOS 首次使用这项能力，需要在系统设置中允许桌搭子的辅助功能权限，授权后重新打开摸鱼广告。
