Windows / macOS **v3.3.0** · Android **v1.4.0**

这次带来了新桌宠、更方便的大厅，还有更顺畅的互动体验。

- **20 只新桌宠来报到**

  Kitty、一二布布、线条小狗、维尼、罗小黑和蜜桃喵加入默认桌宠列表，三端都能使用。你自己添加的桌宠和原有设置会保留。

- **体验期也能玩大厅**

  大厅有了独立入口，可以查看在线伙伴，向他们发送桌宠和留言。是否公开在线由你选择，随时可以退出。

- **第一次使用，有引导陪你上手**

  跟着引导叫出桌宠、互动一次、看段小剧场，再学会暂停和找回。可以随时跳过，也能在设置里重新体验。

- **小剧场看起来更舒服了**

  安卓上的两只桌宠固定在屏幕上方，一左一右轮流说话。普通台词停留约 **3.5 秒**，长台词会多留一会儿，不再同时抢着说。

- **安卓来访更容易看见**

  好友和大厅送来的桌宠会在屏幕中部出现，留言也更方便阅读。横竖屏切换后会自动调整位置。

- **操作更清爽**

  减少多余说明，互动结束后不再残留“正在进行”的提示。安卓桌宠的小菜单会避开桌宠，减少遮挡。

- **陪伴节奏由你决定**

  新增日常台词开关，支持暂停打扰一小时。桌面端菜单也换上了“桌宠小窝”“灵感口袋”等更亲切的名字。

- **修复了一些影响体验的小问题**

  改善互动和小剧场一闪而过、台词提前消失、结束后无法立即重播等问题；修复安卓台词列表出现英文文件名，以及有效体验期间无法正常进入大厅的问题。
