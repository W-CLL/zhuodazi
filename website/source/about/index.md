## 一只住在桌面上的小伙伴

桌搭子从一个很简单的想法开始：人在电脑前待得足够久，屏幕上的一小点回应，也能让一天轻一点。

它不是效率工具，也不会把每一分钟都排成任务。你可以挑一只喜欢的桌宠，让它在角落安静待着；也可以打开互动词包和小剧场，在工作间隙听它说一句俏皮话。

Windows 与 macOS 首次启动都可以免费试用 10 分钟，满意后支付 6.68 元激活。费用会继续投入维护与开发；如果你想要专属角色、动作或功能，也可以联系作者定制。

## 你可以决定相处方式

- 导入透明 GIF，或绑定外部 GIF 资源库，把喜欢的角色放进桌面。
- 选择桌宠、互动词包和小剧场，让它看起来更像你的搭子。
- 在安静、标准、活跃之间调整互动频率，也可以设定鼠标响应和随机走动。
- 在 Windows 或 macOS 的桌面上，留出一块轻松的小地方。
