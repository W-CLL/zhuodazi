# 桌搭子 3.2.10 · 认识新朋友，也能安静陪伴

- 桌宠大厅有了独立入口。可以看到在线朋友、挑选接收人，再把当前桌宠和一句留言送过去。
- 七天体验期也能使用大厅。是否公开在线由你自己选择，另一台设备不会擅自帮你重新加入。
- 需要专心时可以暂停打扰一小时，也可以单独关闭日常台词。提醒和你主动发起的操作仍可使用，来访会留待恢复后展示。
- 手动“换一只”不会再自动打开连续换宠；新设备也会更准确地保留账号已经选择的互动频率。
- 基础陪伴用户也能检查公开更新；macOS 获取新笑话、题目和关怀内容更顺畅。
- Windows 修复了午夜前新建提醒可能立即触发的问题；反馈回复可以查看全文，摸鱼窗口也会清楚说明下一步操作。

大厅来访与私人搭子是两种方式：大厅在有效体验期和正式激活后均可使用；一对一搭子绑定仍需正式激活。来访显示“设备已接收”时，表示已送到设备，并不代表对方已经看见。
