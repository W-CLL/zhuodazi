# 桌搭子 Android v1.5.0

- 新增「我们的日常」：查看累计、本周和按月的互动次数、答题与答对次数、心情分布和心情月历。
- 支持开心、一般、糟糕、想哭、疲惫、烦躁、平静、有盼头八种心情，各有对应回应。
- 新增 5–15、10–30、15–40 分钟互动频率；升级后保留原来的频率，主动切换后使用新档位。
- 支持设置工作日和下班时间，可以选择下班、加班、六点下班或今天休息；选择稍后提醒时最多追加一次提醒。
- 周总结默认在周五 18:00 结算前 7 天，月总结默认在次月 1 日 09:00 整理完整上月；可回看历史周期，进行中的周期只显示实时统计。
- 总结时间、开关和多套文案由管理后台设置，支持新增、编辑、预览和停用。文案按周期轮换，同一期反复查看保持一致；未配置或无记录时显示相应提示。
- 日常数据保存在本机，回答后才计数；页面展示统计、月历与总结，不展示逐条日常记录。
- 互动题目统一从线上自动获取并校验，移除手动换一批内容和缓存管理入口，无需下载离线包。

日常数据从使用此版本后在本机积累，不会自动同步到其他设备。下班提醒需要桌宠服务保持运行；获取新题目和更新总结配置需要联网。
