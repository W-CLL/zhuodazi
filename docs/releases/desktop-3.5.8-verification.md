## 首份候选卸载后仍在运行的原因

## 卸载问题与修复

“跳过反馈并卸载”和“确认卸载”原本都提交卸载意向，原因字段可为空。旧版的关键缺陷是卸载阶段没有关闭运行中的桌搭子；安装阶段的 `CloseApplications=force` 不能替代卸载时清理。运行进程可能阻止删除 EXE，而原代码又仅在 EXE 已删除时发送完成事件。另外，完成事件只发送一次、不检查响应状态，也会漏报。

Windows 现在在所有确认结束后先关闭当前安装目录的进程。按完整路径发送正常退出信号，等待 3 秒后只对仍存活且路径核验一致的进程强制退出；无法确认退出就中止卸载。取消反馈或卸载不会关闭原进程。删除过程中有启动保护，防止正常应用入口再次打开；同会话其他安装副本会短暂受此启动保护影响，但已经运行在其他路径的副本不会被终止。

实际删除后，两种入口都使用同样的完成上报。最多尝试 3 次，重试保持同一事件 ID 和时间；检查 HTTP、ok、事件 ID、设备状态与过期批次标记。401 等永久失败不反复尝试。完成请求使用直连、产品 User-Agent 和禁止重定向，与桌面网络行为一致。临时完成凭据不含永久设备凭据；原用户设置、授权和购买内容保留。

完全离线或意向凭据没有成功获取时仍允许卸载，不能保证后台实时确认。失败不会伪造已确认状态，也不保留常驻进程来等待网络。该修复随新安装器交付，需要覆盖安装 3.5.8 后再卸载，才能替换旧卸载器；仅运行便携版不能更新旧卸载器。

## 内存优化

Windows 不再把全部 GIF 合成帧作为独立 WPF 位图常驻内存。合成结果无损压缩，播放时恢复当前帧并复用一张可写显示位图；无法有效压缩的帧保留原始字节。尺寸、透明效果、处置方式及帧延迟保持一致。隐藏标签页/预览停止播放并释放缓存，重新显示时恢复；读取 GIF 使用文件流，销毁时解绑计时器。

21 个内置及回归素材、两种显示尺寸下的帧缓存与显示缓冲合计由 50,713,344 降到 9,353,879 字节，减少 81.56%。这不是整个客户端的内存降幅。

独立动画进程、相同素材三份同时播放、最大显示尺寸 300 像素的测量：

| 素材 | 旧版私有内存 | 新版私有内存 | 降幅 | 每帧恢复耗时 |
| --- | ---: | ---: | ---: | ---: |
| 默认 50 帧素材 | 63.71 MB | 53.81 MB | 约 15.5% | 0.079 ms |
| 线条小狗 13 帧素材 | 74.52 MB | 55.17 MB | 约 26.0% | 0.454 ms |

这些结果来自隔离动画基准，不代表整个客户端的固定收益。基准两组采用相同的 GC 稳定步骤；生产代码没有强制 GC 或裁剪工作集。每帧增加少量无损解压工作，实际收益与素材、尺寸、帧数和硬件有关。测量方法和命令见 `windows/tests/GifPlayback.Checks/README.md`。

- Windows Release 编译、自包含打包；第二份候选改用 Inno Setup 6.7.1 编译。6.4.3 因覆盖升级缺陷不再允许用于构建。
- 卸载生命周期 34 项、真实进程退出 15 项检查。
- 真实 Inno 安装/卸载 7 个隔离场景，已用 6.7.1 重新运行通过，均保留其他安装目录的同名进程。
- 旧版卸载器覆盖升级到新版、真实客户端保持运行后卸载：版本、退出进程、删除文件、完成回执均通过。
- “跳过反馈”：第一次 503、第二次 200，删除后成功确认；“填写原因”：一次请求成功确认。
- 取消卸载及准备进程退出失败：退出码 1，无完成请求，EXE、进程与安装批次保留。
- HTTP 401 仅请求一次；错误事件 ID 和过期回执不被误认为完成确认。
- 实包离线启动、正常二次启动不误关主实例、卸载期间阻止重新启动、准备卸载后主实例正常退出且无残留。
- GIF 21 个素材 / 1,518 帧逐像素对照；额外线条小狗样本也通过。覆盖透明差分、处置 2/3、循环、600 像素画布、隐藏预览及重载。
- 既有 GIF 素材、默认库升级、小铺视图检查，以及日常交互 111 项 / 实时服务 23 项回归。
- 版本一致性、默认素材包及 diff 格式检查。

第二份候选的隔离安装器回执：`D:\code_file\pro_python\pet\.local-review\uninstall-installer-3.5.8-inno671\results.json`。测试使用独立 AppId、目录、注册表位置、批次文件、合成反馈身份和回环接口，没有操作用户正式安装或线上订单。模拟进程场景另用隔离互斥名称；真实应用回归保留生产退出协议，在用户已手动退出后运行。

## macOS 范围与限制

macOS 两种卸载入口继续共用同一流程。助手补齐按本次 .app 路径关闭残留实例，并严格验证完成回执；切换 GIF 前先解除旧图引用，读取元数据时关闭额外图像缓存。新增完成回执测试，修改文件通过 Swift 语法解析。

当前没有 Mac 环境，因此未做 AppKit 原生编译、XCTest、真实卸载或 macOS 内存测量，也没有生成可交付的 macOS 安装包。Windows 的内存测量不能套用到 macOS。
