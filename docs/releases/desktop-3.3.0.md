# 桌搭子 Windows / macOS v3.3.0

这次带来了新桌宠、更方便的大厅，还有更顺畅的互动体验。

- **20 只新桌宠来报到**：Kitty、一二布布、线条小狗、维尼、罗小黑和蜜桃喵加入默认桌宠列表。你自己添加的桌宠和原有设置会保留。
- **体验期也能玩大厅**：大厅有了独立入口，可以查看在线伙伴，向他们发送桌宠和留言。是否公开在线由你选择，随时可以退出。
- **第一次使用，有引导陪你上手**：跟着引导叫出桌宠、互动一次、看段小剧场，再学会暂停和找回。可以随时跳过，也能在设置里重新体验。
- **操作更清爽**：常用设置更容易找到，菜单换上了“桌宠小窝”“灵感口袋”“贴心提醒”等更亲切的名字。
- **陪伴节奏由你决定**：新增日常台词开关，支持暂停打扰一小时。
- **互动和小剧场更稳定**：改善台词提前消失、上一场演出影响下一场等问题，让连续互动更顺畅。
- **Windows 启动更顺畅**：先叫出桌宠，再检查体验状态，网络较慢时也能先使用基础陪伴和本地引导。
- **macOS 操作少点一步**：从设置中激活成功后，会继续刚才选择的互动或小剧场；隐藏桌宠时，也会一起结束当前演出。
