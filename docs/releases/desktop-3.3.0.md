# 桌搭子 3.3.0 · 花一分钟，认识你的桌搭子

- 默认桌宠换成 20 只新伙伴，包含 Kitty、一二布布、线条小狗、维尼、罗小黑和蜜桃喵。已有自定义 GIF 与图鉴继续保留。
- 新增首次体验引导：认识桌宠、互动一次、看段小剧场，再学会暂停和找回。每一步都可以跳过，随时关闭，之后从设置继续或重看。
- 引导里的问候和约 12 秒双宠短剧来自本机，断网也能体验，不需要邀请好友或导入剧本。试看不会打开自动剧场，也不会记入日常答题记录。
- 升级用户只会看到一次可关闭的新功能提示，已有陪伴设置会保留。体验过程中，自动换宠、走动和主动消息暂时让出空间，真实来访会排队等候。
- 小剧场先告诉你怎么玩，再提供“看一场”与自动上演设置。手动操作遇到隐藏、忙碌等状态时，提示原因和下一步。
- 桌宠大厅有了独立入口和更清楚的在线列表。七天有效体验期也能向在线用户发送 GIF 和留言；是否公开在线由你主动选择，随时可退出。
- 新增日常台词开关和暂停打扰一小时。提醒与手动操作仍可使用，未看的来访会保留到恢复后展示。
- Windows 启动先显示桌宠，再检查体验状态；网络较慢时仍可使用基础陪伴和本地引导，也能从设置重试验证。
- macOS 从设置页激活成功后，会接着执行刚才选择的互动或小剧场，无需再点一次。
- 改善互动内容同步、来访保存、提醒与反馈全文显示。基础陪伴用户也能检查公开更新；检查更新不会计入功能使用统计。
- 改善互动与短剧连续展示：旧提示、旧按钮和上一场演出的收尾不会干扰下一段内容。Windows 到点提醒会等当前问答结束再显示；macOS 隐藏桌宠时会同时结束正在上演的小剧场。
- 陪伴设置换上了更亲切的名字：“桌宠小窝”挑选陪你的桌宠，“灵感口袋”收好悄悄话和小故事，“贴心提醒”记住小事，“心愿信箱”留下建议，“成长日记”查看更新。原有设置和内容都会保留。

大厅与私人搭子是两种玩法：有效体验和正式激活均可使用大厅；与熟人一对一绑定仍需正式激活。进入大厅不会自动加入或发送；标有“演示来访”的内容由软件模拟。“设备已接收”表示内容已经保存到对方设备，不代表对方已经看过。
