# 更新说明维护

每个待发布版本必须提供非空的用户更新说明：桌面使用 `desktop-版本.md`，Android 使用 `android-版本.md`。桌面说明中应明确 Windows/macOS 专属变化。

写清用户现在能做什么、原来什么困扰得到解决，以及需要知道的权限或操作变化。不要用“更新/修复了一些功能”代替具体说明，也不要将接口、字段名、重构等实现细节放在主要更新文案中。

桌面准备脚本和 Android/统一发布工作流通过 `--notes-file` 读取对应文件；缺少说明时阻止创建或修改发布草稿。应用内更新中心上传版本时，复制这份已核验说明到“更新说明”。本次本地工作没有创建、修改或发布任何远程 Release。
