# 桌搭子 Windows / macOS v3.4.0

把心情、答过的题和收工时刻，收进与桌宠一起度过的日常。

- 日常互动新增 5–15、10–30、15–40 分钟档位，已有安装保留原先频率，可按自己的节奏切换。
- 心情增加开心、一般、糟糕、想哭、疲惫、烦躁、平静、有盼头，各有对应回应。
- 可设置工作日与下班时间，到点选择下班、加班、今天六点下班或今天休息；加班可明确延后一次。
- 新增“我们的日常”：查看累计、本周和按月的互动次数、答题与答对次数、心情分布及心情月历。回答后才计数，页面不展示逐条日常记录及修改、删除入口。
- 周总结默认在周五 18:00 结算，覆盖上个截止时间到本次截止时间的完整 7 天，可回看历史周期。
- 月总结在月份结束后、次月 1 日 09:00 开放；正在进行的月份只显示实时统计，不提前生成月总结。
- 管理后台支持调整周/月总结时间与开关，新增、编辑、预览和停用多套文案。总结按周期轮换模板，同一期反复查看保持一致；未配置或无记录时显示相应提示。
- 移除下载离线包功能及“新鲜小趣事”缓存数量/手动补充入口，题库统一通过线上签名批次自动获取。

日常数据从使用此版本后在本机积累，不包含过去版本的线上累计数据，也不会自动同步到其他设备。下班提醒需要桌搭子保持运行；获取新题目和更新总结配置需要联网。
