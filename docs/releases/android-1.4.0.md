# 桌搭子 Android v1.4.0 · 互动一次，看段小剧场

- 新增可以亲手体验的使用引导：叫出桌宠、认识操作、互动一次、看段小剧场，再学会暂停和找回。随时可以跳过、关闭或继续，完成后也能重看。
- 引导的互动与短剧使用本地内容，断网也能体验，不需要好友或导入文件。试看不会开启自动剧场，也不会记入日常答题记录。
- 升级用户只看到一次可关闭的新功能提示；已有设置继续保留。教学期间自动换宠和主动消息暂时暂停，真实来访排队等候。
- 首页“切换形象”“说句话”和小剧场会先检查悬浮权限与桌宠运行状态。准备中、隐藏、正在演出或操作失败都有明确提示，实际执行后才显示成功。
- 小剧场先展示玩法和“看一场”，随后是自动设置；自定义剧本收进单独区域，第一次使用更容易上手。
- 悬浮权限在叫出桌宠时说明，通知权限在需要通知恢复入口或提醒时说明。没有通知权限，也能从首页显示桌宠、恢复触摸。
- 底部导航新增独立“大厅”，七天有效体验期也能向在线用户发送 GIF 和留言。加入公开在线需要你主动选择，可以随时退出。
- 新增日常台词开关与暂停打扰一小时；关闭主动趣味互动后，状态说明会明确告诉你仍可手动体验。
- 改善来访排队保存、互动内容同步和账号偏好保留。检查更新不会计入功能使用统计。
- 修复互动卡和小剧场偶尔刚出现就消失的问题。后台检查体验资格或同步设置时，可以继续看完、继续回应；引导演示和日常玩法都适用。
- 修复上一条气泡的关闭动作影响新台词的问题，连续对话更稳定。
- 修复停止后马上重播被上一场演出打断的问题；隐藏桌宠、开启穿透时，当前互动和演出也会正确结束。
- 互动结束后，页面会自动恢复可用，不再留下“当前场景还在进行”的提示。互动页更简洁，保留玩法、开始与结束等需要的操作。
- 点击桌宠展开的小菜单会避开桌宠，常用操作集中在六个按钮里。
- 小剧场的两只桌宠固定在屏幕上方，一左一右轮流说话。一方说完另一方再接话，每页台词至少停留 6 秒，长句延长或分段显示；结束后桌宠回到原来的位置。
- 首页、互动、桌宠和引导页面进一步精简，常用操作更容易找到。体验期也能加入大厅，与在线的人互发桌宠。

Android 沿用自身版本序列，本次包含新增功能，从 v1.3 系列升级为 v1.4.0。大厅在有效体验和正式激活后可用，私人搭子绑定和导入自己的 GIF 仍需正式激活。标有“演示来访”的内容由软件模拟，进入大厅不会自动加入或发送。
