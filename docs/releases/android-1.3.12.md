# 桌搭子 Android 1.3.12 · 大厅更好找，来访不再错过

- 底部导航新增独立“大厅”。在线朋友以卡片展示，可以先看清发送对象，再送出当前桌宠和留言。
- 七天体验期也能向大厅里的在线朋友发送桌宠。公开在线需要你主动加入，随时可以退出。
- “我的搭子”保留为独立页面，一对一绑定仍需正式激活。
- 隐藏桌宠、开启穿透或暂时不方便查看时，收到的来访会排队保存；恢复显示后再依次出现，连续来访不会互相覆盖。
- 新增日常台词开关和暂停打扰一小时。需要专心时更安静，提醒与手动操作仍然可用。
- 改善首次设置和互动内容同步：试用初始化不会跳过新用户默认，已有账号的互动选择会保留，六类互动内容也能正常补充。
- 昵称长度、词包默认选择与同步失败提示更清楚；后台撤销购买入口后，手机不会继续保留旧链接。

导入自己的 GIF 仍需正式激活，最多 3 个；外部图鉴、小剧场和提醒在有效体验期即可使用。
