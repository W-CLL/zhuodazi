# 小铺订单记录、自动安装与免费内容

日期：2026-10-29。只修改 Windows 和本地后台，不发布线上；用户自行操作界面与付款验收。

本轮最终汇总与后续 macOS 范围见 [Windows 调整汇总与 macOS 跟进范围](2026-10-29-windows-review-and-macos-scope.md)，包含后续追加的后台订单、购买者设备与昵称、小窝隐藏路径及左右 5:5 布局。

## 已付款订单与安装

“桌宠图鉴”页顶栏增加“订单记录”，点击打开独立弹窗。记录持续保存在后台，按当前激活账号隔离，包含商品名称、订单号、五位备注码、订单金额、锁定版本、创建/到期/付款/取消时间及状态。待付款订单可重新查看原收款信息；已付款订单显示付款验证成功及安装状态，过期和取消记录也保留。

识别到已付款订单后，客户端自动下载并安装该订单锁定版本，仍经过服务端权益、签名描述、包哈希及逐文件校验。安装过程串行去重，已安装的相同版本不重复下载；失败不丢失订单，可从记录弹窗重试。安装不主动启用，用户从桌宠详情点击“启用这个桌宠”。订单的短码本身不能用于下载授权。进入小铺后，订单监听在切换主侧栏或隐藏设置时仍持续，整个视图销毁或退出软件才停止；重新打开小铺可恢复已付款但未安装的订单。

订单历史接口为 `GET /api/pet-market/orders`，使用现有账号凭据。响应包含 `orders`、`serverTime` 和 `nextCursor` 分页游标；每页最多 100 条且订单 JSON 不超过 700 KB。客户端逐页合并，最多处理 10,000 条，防重复游标和跨页重复记录；超过上限明确提示。待付款保留冻结的收款目标，终态记录不再附带可付款的二维码。存在待付款订单时每 3 秒同步，其他时候每 30 秒同步。同一商品如有多个已付版本，自动安装最新付款记录对应版本，旧记录保留，避免反复替换安装。

## 免费小剧场与互动词库

小铺顶部增加“桌宠图鉴”和“小剧场 / 互动词库”两个标签页。免费内容页提供名称搜索、分类切换，以及每个包的下载、安装和启用状态。

流程为：后台上传并上架 → 客户端刷新目录 → 点击“免费安装” → 自动下载、校验与安装 → 显示“已安装 · 待启用” → 用户点击“启用”。没有订单、付款或单独收费步骤。

- 新安装的互动词库不切换当前词库，多套小铺词库可以同时启用并共同提供台词；点击停用仅改变启用状态，已安装内容保留。
- 新安装的小剧场默认为停用，不加入随机剧本候选；用户启用后加入候选。自动演出仍由“陪伴日常”的小剧场开关控制，不因下载或启用内容而打开定时演出。
- 既有本地剧本未存储启用字段时默认为启用，保留原行为；既有本地词库选择保留。下载不收费，内容实际运行沿用原有的体验/激活能力规则。
- 后续按用户确认调整为互动词库和小剧场分别最多启用 10 个，安装收藏不受启用数量限制，可在“灵感口袋”多选启停。详见同目录 `2026-10-29-content-selection-and-conversation.md`。
- 文件先完成下载和 SHA-256 校验，再全部解析成功后一次性保存。仅接受安全路径的 JSON 和可选 README，无执行文件；单 JSON 最大 256 KB、JSON 最多 80 个、总解压大小不超过 20 MB。

后台沿用“资源包”菜单，小铺提供“管理小剧场 / 互动词库”跳转。上传 ZIP 时选择分类，填写名称、简介、版本和上架状态；之后可编辑信息、上下架。旧包和新包均须通过真实 ZIP/JSON 内容校验才对外展示。接口沿用 `GET /api/public/resource-packs` 与 `/resource-packs/:id/download`，免费匿名下载；预览客户端只连接配置的本机地址，不跟随外站重定向。

## 布局

按用户最后确认固定为左右 5:5 布局：左侧桌宠目录、右侧预览与付款等宽，取消右侧最大宽度 340 的限制，窗口变宽时两栏同步伸展。左右分别纵向滚动。取消按窗口宽度切换上下排列的逻辑；窗口过窄时保留两列并允许横向滚动，不改变左右关系。详情中的预览图宽度为 118，收款人名称可换行。订单记录使用独立弹窗。

小剧场 / 互动词库使用资源卡片展示，小剧场使用暖色标识，词库使用绿色标识，统一名称、简介、免费标识和安装状态的层级。资源视口宽度达到 760 时双列展示，较窄时使用单列卡片。卡片底部根据状态显示“免费安装”“启用”或“停用”，明确区分未安装、已安装待启用及已启用；支持搜索、分类筛选及清除筛选，下载后不自动启用。
