# 桌宠小铺付款整合

日期：2026-10-29。范围：完整 Windows 客户端、本地后台和本地微信付款监听；不部署或更新线上。

后续变更：付款确认后现已改为自动下载安装，启用仍由用户决定，并增加可重新打开的订单记录。最新行为与免费内容标签页见 [订单记录与免费内容](2026-10-29-shop-orders-and-free-content.md)。本文中“主动点击下载安装”为该轮付款页验收时的历史行为。

## 补齐的问题

此前新小铺只显示金额、备注短码和倒计时，收款码与好友转账操作指引仍在旧调试窗口，新 `18767` 后台也未接入真实监听。免费桌宠的领取、安装和启用已验证，但收费商品不能据此称为完整付款流程。

本轮把收款设置、付款卡片、订单收款目标和监听健康检查接到同一条链路：

`后台设置收款方 → 监听建立基线并在线 → 用户创建订单 → 显示金额与收款目标 → 微信转账说明填写短码 → 匹配订单 → 开放下载安装`

## 用户看到的付款流程

- 在“桌宠小铺”选择收费角色，点击“购买 · ¥2.80”或“购买 · ¥5.80”。
- 下单后付款卡片出现在详情区顶部，显示商品、订单锁定金额、五位短码、收款昵称、微信号和剩余时间；可复制短码和微信号。
- 本地当前采用用户指定的好友转账方式：昵称“小王”，微信号 `wcl_lcw627`。信息由后台设置返回，客户端不硬编码。
- 用户自行打开收款方的微信聊天，核对金额，发起转账；转账说明完整填写本单短码。短码为三个数字和两个英文字母，不区分大小写。发送聊天文字不算填写转账说明。
- 按用户确定的政策，识别到来源、收款账号、金额、短码和订单时间匹配的个人转账消息，即确认订单并开放下载；不要求另行点击收款，不以个人转账的到账状态作为前置条件。
- 收款码是后台可选方式，上传 PNG/JPEG 收款码后可展示；该方式保留收款核对流程，不冒充好友转账自动确认。本轮未提供实际收款码图片。
- 15 分钟内未完成的订单到期后隐藏付款卡；订单查询或监听断线时保留订单并显示等待恢复的提示。下载和启用仍由用户主动点击。

## 后台设置与接口

小铺管理页新增“收款设置”，包含启用开关、好友转账/收款码、收款昵称、微信号、二维码上传预览及说明，同时显示监听状态。相关写操作仍要求后台登录和 CSRF 校验。

| 接口 | 用途 |
|---|---|
| `GET /api/admin/pet-market/payment-settings` | 读取收款设置和当前可用性 |
| `PUT /api/admin/pet-market/payment-settings` | 保存公开收款信息 |
| `POST /api/pet-market/payment-heartbeat` | 既有付款桥接令牌认证的监听健康回报 |
| `GET /api/pet-market/catalog` | 在 `payment` 中返回当前收款方式和可用性 |
| `POST /api/pet-market/orders` | 新订单锁定金额、版本和收款目标，返回 `order.payment` |
| `GET /api/pet-market/orders/:id` | 返回订单状态、冻结的收款目标及对应监听可用性 |

公开 `payment` 包含 `enabled`、`available`、`method`、`recipientName`、`recipientAccount`、`qrCodeDataUrl`、`instructions`、`unavailableReason`、`listenerOnline`；不包含桥接令牌或微信内部账号标识。二维码仅允许有大小限制的 PNG/JPEG data URL，Windows 不为二维码访问任意外部地址。

收款设置默认关闭。新订单要求有效收款目标和对应消息来源的健康监听；仅有非空开发令牌或占位账号不会开放新下单。心跳只报告账号与各支付来源的读取状态，不携带聊天或付款详情。停止时立即报告离线，异常退出则由后台的 60 秒时效判定离线；订单有效期仍为 15 分钟。

微信写入消息时，wxlocal 的一致性校验可能抛出 `BusyError`。桥接对同一来源最多尝试三次；若仍仅为短暂忙，不发送新的心跳，也不刷新成功时间，由最后一次真实成功读取的 60 秒时效自然计时。持续忙超过该时效会暂停付款，恢复成功读取后自动恢复；其他读取错误、数据饱和或停止立即报告异常。实机曾观察到一分钟以上的源忙，因此仍可能出现短暂等待提示；没有绕开数据库一致性校验，也没有修改 wxlocal 源码或微信数据库。

已有订单不随后台修改收款信息而悄悄更换付款目标。旧开发订单只有在尚未过期、尚无收款快照、内部目标恰为开发占位值时，才可在真实收款配置和监听就绪后首次绑定，保留订单 ID、短码、金额、版本和原有效期，并记录审计；已有真实收款账号的订单不自动改绑。

## 本地启动与隔离

在 `zhuodazi` 目录执行：

```powershell
pwsh -File windows/scripts/start-pet-shop-preview.ps1 -NoBuild
```

默认使用 `http://127.0.0.1:18767` 和 `.local-review/pet-shop-showcase-20261029`，从旧 `local-market-transfer` 配置中只读复用 wxlocal 的源码路径、收款账号目录与已有密钥文件位置。新环境使用自己的令牌、游标、发件队列和监听状态；不复制旧监听数据库，不重放旧支付事件。首次成功读取只建立历史基线。

停止本轮后台与监听：

```powershell
pwsh -File windows/scripts/stop-pet-shop-preview.ps1
```

停止脚本只向本轮标记匹配的路径发送停止信号，不停止其他环境，也不操作微信。监听不发消息、不加好友、不点击收款。
