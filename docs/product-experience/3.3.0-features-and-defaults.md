# 桌搭子 3.3.0 功能与默认设置

核对日期：2026-09-20。本文描述本地待验收代码，不表示已经上线；线上下载和后台远程配置本轮未查询。桌面端为 v3.3.0，Android 沿用独立版本序列，为 v1.4.0，内部构建号为 20。修复递增末位、新增功能递增中间位、大版本升级递增首位，详见 [版本规则](../releases/versioning.md)。

## 首次体验与恢复

| 能力 | 当前行为 |
|---|---|
| 新安装欢迎 | 基础桌宠可展示后，提供一分钟体验入口；Android 先由用户允许悬浮显示 |
| 升级提示 | 根据已有本机数据识别老用户；缺少新引导字段不会触发完整强制教学，只给一次可关闭提示 |
| 第一步：认识操作 | Windows 拖动、双击、右键；macOS 拖动、右键、菜单栏；Android 拖动、点击菜单与首页 |
| 第二步：本地互动 | 稳定问候与选择按钮；实际显示且回应或明确关闭后推进，不记录普通心情或答题统计 |
| 第三步：本地短剧 | 无需网络、邀请好友和导入剧本；可以结束、重试或跳过。Windows/macOS 约 12 秒；Android 两只桌宠固定在屏幕上方左右两边，每页至少 6 秒，默认三组对白依次播放约 36 秒，长句或窄屏分页会延长 |
| 第四步：暂停与找回 | 说明一小时暂停、恢复、隐藏、穿透与完全退出，不强制真的暂停一小时 |
| 进度 | 保存当前步骤、完成、跳过和主动关闭；中途关闭后可继续，完成后可主动重看 |
| 打断处理 | 教学暂缓自动换宠、移动、日常台词、互动、小剧场；真实来访排队；隐藏和暂停不会冒充步骤完成 |
| 完成后的去向 | 手动互动、小剧场、大厅；进入大厅不自动公开昵称、不自动发送 |
| 演示来访 | 入口和内容明确区分软件演示与真实收件；旧首次定时演示由新教学流程取代 |
| Windows 网络等待 | 先显示桌宠，再异步验证体验；设置可重试；受保护功能继续检查真实权益 |
| Android 操作结果 | 授权、启动、展示逐步处理；原生服务回执确认实际执行，忙碌或失败不报成功 |
| Android 互动结束 | 页面运行时每 800 毫秒同步悬浮服务状态，普通互动结束后恢复操作；不向用户显示内部场景状态横幅、缓存数量或内容目录版本 |
| Android 点击菜单 | 六个常用操作，菜单按屏幕空间放在桌宠上方或下方，菜单和桌宠各占独立区域 |
| Android 剧场阅读 | 两只桌宠固定在安全区域上方左右两边；一方说完再轮到另一方，每页至少 6 秒，长句按内容延长并自动分页；旋转后重排并重新给予当前页阅读时间，结束后恢复原位置 |
| macOS 激活接续 | 从设置发起互动/剧场需要激活时，成功后继续原动作，取消留在原页面 |

## 日常功能清单

桌面页面采用统一主题名称：陪伴日常、桌宠小窝、灵感口袋、桌宠大厅、贴心提醒、心愿信箱、成长日记。macOS 原有独立资源库页面称“桌宠图鉴”；Windows 的图鉴管理保留在“桌宠小窝”内。“灵感口袋”包含趣味互动、悄悄话和小剧场故事，检查更新等功能按钮保持直白易懂。

| 模块 | 具体能力和边界 |
|---|---|
| 常驻与入口 | Windows 托盘和桌宠右键；macOS 菜单栏、Dock/设置；Android 首页、悬浮菜单和系统通知。关闭设置页不等于退出桌宠 |
| GIF 展示 | 透明背景、动图循环、拖动、投掷、边缘响应；内置图鉴可直接使用 |
| 外观 | 大小、透明度、水平镜像；电脑可设置始终置顶；Android 通过系统悬浮层显示 |
| 行为 | 活泼、害羞、黏人、混乱；自动走动；电脑支持鼠标跟随和躲避；可关闭对应开关 |
| 换宠 | 手动换一只、自动按间隔换宠；手动换宠不擅自开启自动换宠 |
| 自定义 GIF | 最多 3 个；校验动图大小和格式。Windows/macOS 基础陪伴即可导入；Android 需正式激活 |
| 外部图鉴 | 有效体验或激活后可用，最多 3 个资源目录；文件路径和资源存在本机 |
| 日常台词 | 待机、走动、触摸/拖动等场景台词；独立开关，可与趣味互动分别控制 |
| 趣味互动 | 心情问候、笑话、题目、谜语、脑筋急转弯、关怀等服务端内容；手动与自动入口；不支持任意输入的开放聊天 |
| 内容同步 | 本地缓存、联网补充、内容版本与签名校验；互动开关和频率可按账号同步；已有账号选择优先 |
| 词包 | 使用内置台词包；桌面可导入自定义 JSON/TXT 词包、切换与删除；Android 选择内置词包 |
| 小剧场 | 两只桌宠演对白，手动观看无需真人好友；可另行开启自动上演；内置剧场和自定义剧本分区说明 |
| 自定义剧本 | 导入、选择、删除及格式帮助；桌面最多 10 个；不导入也可使用内置对白 |
| 临时安静 | 暂停主动打扰一小时，提前恢复；抑制主动台词、自动互动、自动剧场与来访展示；提醒和手动功能可用 |
| 停止当前场景 | 停止剧场/来访；教学演示可单独停止，未完成步骤保留 |
| 提醒 | 自定义时间、文字、每日重复与可选 GIF；应用需保持运行；不会预先替用户创建提醒 |
| 独立桌宠大厅 | 查看在线用户、公开昵称、选择接收人、发送当前 GIF 和留言、退出公开在线；空列表和错误状态明确 |
| 大厅权益 | 有效体验和正式激活均可用；用户主动加入；另一台设备不会重新覆盖账号已作的公开选择 |
| 私人搭子 | 正式激活后用搭子码与熟人绑定，查看关系、发送当前 GIF、解除绑定；与公开大厅分开 |
| 来访展示 | 对方宠物临时来访，不替换原桌宠；留言可展示；设备先保存再回执，忙碌/隐藏/暂停时排队 |
| 来访与账号 | 重启保留待看内容；首次体验转激活可继承体验来访；换到另一正式账号保持隔离 |
| 收件状态 | “设备已接收”只代表已保存到设备，不代表对方已读 |
| 体验与激活 | 七天有效完整体验，结束后基础陪伴保留；6 位激活码与 8 位搭子码用途不同；一组购买码最多 2 台设备 |
| 摸鱼模式 | 电脑端提供对应窗口与说明，受有效体验/正式激活及远程功能开关控制；Android 无此功能 |
| 更新 | 三端独立架构渠道，查看用户更新说明、检查/下载更新；基础陪伴也能检查公开更新；更新接口不进入功能使用统计 |
| 反馈 | 电脑提交问题或建议、查看完整正文与处理回复；每台设备最多 3 条进行中 |
| 开机启动 | 电脑登录启动、Android 开机启动；默认关闭，仍受系统权限与后台策略影响 |
| 找回 | Windows 托盘显示，Ctrl+Shift+P 关闭穿透；macOS 菜单栏显示/恢复；Android 首页与允许通知时的通知入口 |
| Android 权限 | 悬浮显示按需申请；隐藏/穿透恢复或提醒时解释通知用途；拒绝通知仍可从首页恢复 |

以下是新安装的**本地代码初值**，不是这台机器的个人设置。首次联网可应用服务端对新用户的默认性格、互动模式和剧场间隔；已有本机设置和账号同步结果另有优先级。本轮没有查询生产远程配置，不能把下面的本地初值当成当前所有线上新用户的最终值。

## 数据与发布边界

引导、外观、图鉴路径、自定义素材、剧本、提醒保存在本机，不构成整套云备份。账号、激活、搭子与大厅资料、互动频率/开关走对应服务。实际大厅发送和线上内容仍需可用的配套服务端。

本轮已有 Windows、Android 本地验收包。macOS 源码已修改，必须在 Mac 上运行 Swift 构建/测试并做双架构与界面验收后再发布。最新修复与人工步骤以工作区 `reports/互动体验与菜单主题验收-2026-09-20.md` 为准，历史首次体验及闪现修复报告保留用于对照。
