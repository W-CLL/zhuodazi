## 本轮范围

将原先少量验证素材换成可浏览的角色目录，商品名称、简介和列表使用正常产品文案。后台支持从本地角色文件夹或多选 GIF 上传，设置价格、标签、精选、默认款和有限预览，再由 Windows 小铺展示。完整流程为：

`新增草稿 → 定价与标记 → 上传角色素材 → 校验并上架 → Windows 浏览 → 激活后领取或购买 → 下载校验 → 安装 → 主动启用`

本轮没有新增真实付款，没有启动新的微信监听，也没有接受或操作微信转账。支付匹配沿用此前实现；五位备注码不作为下载或使用凭据。后台上架不代表已经发布到公网。

## 后台完整操作

1. 打开本地后台 `http://127.0.0.1:18767/admin#pet-market`，进入“桌宠小铺”，点击“新增桌宠”。填写唯一商品标识、名称与简介，初始状态保留为“草稿”。商品标识创建后不可修改。
2. 设置“是否收费”：免费款选择“免费 · 激活后领取”；收费款选择普通款 ¥2.80 或复杂 / 热门款 ¥5.80。免费和收费模式可以在后续编辑中调整。
3. 添加标签，最多 4 个，每个不超过 12 个字，使用逗号、顿号或换行分隔；可勾选“精选推荐”。只有免费且已上架商品可设为默认；设置新默认会替换原默认标记。
4. 保存草稿后点击该商品的“上传资源”，填写新的语义版本，例如 `1.0.0`。选择“角色文件夹”或“多选 GIF 图片”，选择本地素材；原有含 `pet-market.json` 的 ZIP 包仍可上传。
5. 检查选中素材数量与大小。单版本接受 1–80 个 GIF，每个不超过 8 MB、宽高不超过 2048，全部素材和最终资源包不超过 64 MB。文件夹中的非 GIF 不作为桌宠素材。对源目录超过 80 个文件的情况，先挑选该角色的一组素材或使用多选 GIF，不直接整目录提交。
6. 勾选“资源校验通过后立即上架”，点击“上传并校验资源”；也可以先上传，再从列表手动上架。服务端使用 `gif-files` 上传协议生成清单和逐文件 SHA-256，检查 GIF 内容、路径与大小；无有效资源的商品不能上架。新版本不覆盖已购版本。
7. 编辑“每包开放预览的内容”，选“后台手选（最多五个）”，填入上传清单中实际存在的素材路径，一行一个。也可选择“前五个素材”或“关闭预览”。本轮目录全部采用手选 5 个预览。
8. 回到列表查看封面、价格、标签、默认 / 精选标记、上架状态和资源版本。通过名称、标签、商品标识搜索，或按免费 / 收费及上架状态筛选，确认商品可找到。

选择文件夹和多选 GIF 都走同一套服务端校验逻辑。文件路径不能穿越目录、使用绝对路径或大小写重复；ZIP 还会检查清单及实际文件的一致性。包内不运行代码。

## Windows 查看与使用

在完整 Windows 本地预览的侧栏进入独立“桌宠小铺”菜单，刷新目录，按名称或标签搜索，使用免费 / 收费等筛选浏览角色卡片。卡片呈现角色封面、素材数、价格和标记；点击后可查看允许公开的代表素材。

正式激活的本地身份可以领取免费角色或创建付费订单。权益确认后主动点击下载并安装，客户端核验签名、版本、包哈希及逐文件哈希；安装完成再主动选择启用，桌面才切换到该角色。安装本身不自动替换当前正在使用的桌宠。

已有权益锁定获得时的版本，后台发布新版本不等于改写旧订单或旧安装。源素材目录、后台资源、客户端下载和启用状态分别保留，便于检查完整流程中的每一步。
